One letter for my day, for make.fun's "One Letter for Your Day" bounty: **W**.

> **W — whack-a-mole.** Tuesday 24 November 2026 was a day of bounties popping up one an hour, each one smacked down as fast as it appeared, only for the next to surface. Whack-a-mole is the whole day in one picture: the monitor, the queue, the next slug.

## Run it

```sh
node main.ts
```

`main.ts` reads the letter from `line.txt`, checks it is exactly one capital letter A–Z, and writes exactly that one character (no newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
